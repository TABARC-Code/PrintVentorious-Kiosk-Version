# Description

PrintVentorious Kiosk: a customer-facing quote page for a 3D print farm. Browse the catalogue, pick an item and quantity, get a price worked out server-side, add an email address, send. The request lands in your inbox or a webhook. Nothing is kept on the customer's device.

Built for easy reading: dyslexia-friendly font choices, size and spacing controls, plain wording, three simple steps.

Stack: Node, Express, SQLite (better-sqlite3), plain HTML/CSS/JS on the front. No framework, no build step.
